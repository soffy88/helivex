# 全面诊断:为什么不盈利,以及该整什么 — 2026-07-22

本文档基于三条独立证据线交叉验证:①`paper.fills`/`paper.signals` 全历史(2026-07-02~07-22,2939 fills)的逐策略 FIFO 归因重算;②`.gate_trials.json` 29 次 gate 试验账本 + 判定逻辑的 git 考古;③docs/ 下 R3–R17、TPB-001、LER-001 全部研究文档。分析脚本可复跑(见文末)。

## 0. 裁决(TL;DR)

**"几个策略都无法盈利"不是参数问题,是三层结构性问题的叠加,按重要性排序:**

1. **没有被验证的 edge 在交易。** 29 次 gate 试验:28 次 FAIL/REJECT,唯一的 PASS(trend_follower_port,trial #23)是 2026-07-10 门槛治理性放宽后的弱通过(见 §2)。当前 16 条真实下单的策略腿里,**除 trend_follower 外全部是 gate FAIL 或 UNVALIDATED 状态在跑**——paper 模式治理闸只 WARN 不拦(`paper/run.py:133-138`)。已被自己的回测在 6.5 年数据上证伪的策略,继续跑纸面不会变出利润。
2. **成本墙是主导性 PnL 因子。** 直到 07-20 全系统 100% taker(5bps/边≈10bps/回合)。20 天实测:scalp 三腿 1381 回合毛 PnL **-$0.69(与零不可分)**,估算费 **-$10.2**——费率是全组合唯一稳定、方向确定的收益流,而且是负的。这正是 R5.1("310%/年成本")、TPB-001("成本吃掉 gross 98.6%")反复得出的结论,现在被真实成交第三次确认。
3. **20 天 paper 数据本身没有判别力。** 07-20 之前所有策略(除 scalper_v2)单笔名义被 min_quantity bug 压到 $0.77–$6.33(配置 $50,差 8–65 倍),PnL 全是噪音;账户级余额 +$7.95 是**跨策略串仓轧平的假象**,逐策略真实归因合计 **-$54.88**(差 $62.83,机制见 §1.2)。真正干净的数据从 07-21 才开始积累。

**定位错位是根因的根因**:R6_PAPER_FRAMEWORK 明确写了"paper 赚 ≠ 有效;paper 只验证执行假设(滑点/成交率/延迟),不验证 alpha"。但当前组合的运营形态——7 策略 × 3 标的、风险定仓、期待 PnL 转正——是一个"盈利组合"的形态。**要整的不是让这些策略盈利(gate 已证明做不到),而是把组合收敛回它唯一能兑现的价值:执行测量 + 给唯一存活候选积累样本。**

### 1.2 账户 +$7.95 是假象

账户级 FIFO(gateway `/paper/account` 口径)把 A 策略的空单和 B 策略的多单在同一标的上互相轧平,跨策略对冲的"利润"计入账户却不属于任何策略。**Σ策略级 = -54.88,账户级 = +7.95,差 62.83。** 这是 MEMORY 里"net_position 是账户级"问题在 PnL 侧的镜像。看板上的余额曲线不能用于任何策略判断;逐策略含费归因才是真数。账户级还挂着 54 个未平 lots(BTC 23/ETH 12/SOL 19)在继续制造这个口径差。

### 1.3 判别力:这 20 天能证明什么

- **07-21 前的数据仓位失真 10–60 倍**(ee35633 修复),此前 PnL 与仓位修对后的世界不可比。样本从 07-21 重新计,scalp maker 实验自己也在 YAML 里这么声明了。

## 2. gate 账本的真相:唯一的 PASS 是什么成色

`.gate_trials.json` 考古发现:**trial #20、#21(FAIL)与 #23(PASS)的 DSR/PBO/OOS/gross Sharpe 逐位相同**——策略和数据没变,变的是判定标准。中间隔着 commit 62b2c5b(2026-07-10"门禁过严治理"),该提交依用户方针("门禁不要太严,有风控即可")做了:N 棘轮修复(合理)、kurtosis 退化修复(合理)、**mean−std>0 放宽为 mean_OOS>0、全标的通过放宽为多数通过、真 DSR 从 95% 显著性门槛降为仅报告**(实质放宽)。

因此 trend_follower_port 的 PASS 语义是:**"三标的 OOS Sharpe 均值为正(0.33/1.09/0.56)+ 双 PBO<0.5,即'没有证据表明它是过拟合的'"——不是"有统计显著的 edge"**(真 DSR 仅 0.01/0.07/0.06,BTC 的 mean−std 口径 DSR 还是 -0.48)。这个放宽本身是有书面 rationale 的合法治理决定,不翻案;但据此给 trend_follower 的资金和预期,应该按"弱候选"而不是"验证通过"来标定。

## 3. 结构性问题(不动这些,换任何参数都没用)

1. **Donchian 家族三重曝光**:donchian_4h(4H)、trend_follower_port(1D)、spot_trend_1d(1D long-only)全是通道突破,同 3 个标的。同一波趋势三者共振,组合是"名义分散、逻辑集中";R4 系列已证明这个信号族在 chop(~75% 时间)持续放血。
2. **费率结构**:除 scalp maker 实验外,所有策略 IOC 市价单,10bps/回合。1H 及以下周期的策略,毛边际(实测 ≤2bps/回合)结构性小于成本。TPB-001 还证明了 maker 入场也救不了:出场 88% 走 taker 止损,maker 挂单成交率仅 10.5%。
3. **仓位分配与验证强度成反比**(反模式):风险定仓 `qty_usd = min(1000, 50×entry/sl_dist)` 使**止损越紧名义越大**——5m 策略(最未验证、成本最敏感)顶到 $1000 cap,日线策略(唯一 PASS)按风险缩到几百。scalper_v2_eth 一条腿亏掉全组合亏损的 35%,就是这个公式分配的。
4. **vwap_mr_1h 的"2σ"仍是假极值**(07-19 定的 P0 至今未做):σ 窗口 3 个样本,|z|>2 在 26% 的 bar 成立。但鉴于该策略 gate 三连 FAIL 且 20 天仅 $262 成交额,修 σ 是给已证伪策略打磨——建议直接并入退役裁决(§4)。
5. **孤儿/清理单继续污染统计**:190/2939 fills 无 signal_id(6.5%,集中在 a32a2c7 修复前),donchian 的回合数里近半是 07-12 停机风暴清理单。强平/清理单不打标,低频策略的纸面统计永远不可读。
